#  Product List Full Stack App

A full-stack web application that lists jewelry products with real-time price calculation based on gold rates. It includes filtering, responsive design, and dynamic image handling.

---

##  Features

-  Displays a list of products with name, weight, price, and popularity
-  Real-time dynamic price calculation using gold price API
-  Color picker to switch between product images
-  Popularity score converted and shown out of 5
-  Carousel with arrow and swipe support (desktop + mobile)
-  Optional filtering (by price and popularity)
-  Responsive UI

---

## ⚙️ Technologies

### Client
- **React**
- **Vite**
- **Tailwind CSS**
- **Axios**

### Server
- **Node.js**
- **Express**
- **dotenv**
- **Axios** (for external gold price API)
- **CORS**
